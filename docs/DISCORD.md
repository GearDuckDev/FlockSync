## FlockSync: your guild, in sync

An in-game addon for everyone, a Windows sync companion for collectors, and
a guild-hosted web dashboard for planning.

**Members:** install the main FlockSync addon, complete the walkthrough, and
play. No desktop app or website account is required to share your character
data with your guild's collector.

**Officers/admins:** use FlockSync + AppHelper and one desktop download.
Sign in with your authorized website account, choose the WoW folder, and let
saved addon data sync after logout or `/reload`.

**What you'll find:**
- Linked mains/alts, roles, gear, and availability.
- Team planning, groups, bench, and role coverage.
- Guild crafting searches and shared gear goals.
- Attunements with collapsible alts and individual progress.
- Loot/attendance and an officer task board.
- Optional web themes (default: None) and desktop start-minimized support.

**Screenshots show real web/desktop UI with fictional demo data. Desktop sync
responses are simulated; these are not in-game addon captures.**

Downloads: https://github.com/GearDuckDev/FlockSync/releases
Setup: https://github.com/GearDuckDev/FlockSync/blob/main/DEPLOYMENT.md

Regular members need only the main addon. Collectors need AppHelper, desktop,
and an OFFICER/ADMIN server login. Shared information depends on your guild's
active collection and sync setup. Release-channel, still pre-1.0.
